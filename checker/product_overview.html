ครบทุกการใช้งานในครัว

ออกแบบจากการใช้งานจริง ลดขั้นตอน เพิ่มความเร็ว

🔄
Real-time Queue
ดึงคิวจาก Pixel POS อัตโนมัติทุก 15 วิ ไม่ต้อง refresh มือ แสดงสถานะรอทำ / กำลังทำ แบบ live
✅
Checkout & Undo
กด Checkout ยืนยันรายการเสร็จ กด Undo ย้อนกลับทันทีหากกดผิด — ป้องกันข้อมูลหาย
🔢
Checkout 3 โหมด (qty > 1)
โหมด 1 ทีละ 1 รายการ  ·  โหมด 2 จบทั้งหมดครั้งเดียว  ·  โหมด 3 เชฟเลือกจำนวนเองจาก popup
🔒
2-Step Checkout
กดครั้งแรก "ยืนยันไปครัว" ก่อน แล้วค่อย Checkout — ป้องกันกดพลาด เหมาะครัวที่ต้องการความแม่นยำ
📷
Barcode / QR Scan
สแกนเนอร์ USB (keyboard) และกล้องมือถือ / tablet สแกนต่อเนื่องอัตโนมัติทุก 800ms รองรับ QR code
🔔
เสียงแจ้งเตือน order ใหม่
เล่นเสียงเมื่อมี order ใหม่ อัปโหลดไฟล์เสียงเองได้ (.wav/.mp3) ทดสอบเสียงได้จาก Settings
⏱️
Timer & Color Alert
นับเวลาทุกรายการ การ์ดเปลี่ยนสีเมื่อใกล้เกินเวลา (เหลือง) และเกินเวลา (แดง) ตั้งค่าเกณฑ์นาทีได้เอง
🗂️
SET Menu
แสดงชุดอาหาร (parent/child) แยกชัดเจนด้วย label สีเขียว เชฟรู้ว่าต้องทำอะไรครบในชุดเดียว
📍
Zone Filter
แต่ละจอดูเฉพาะโซนที่รับผิดชอบ ล็อคโซนไม่ให้เปลี่ยนโดยไม่ตั้งใจ จำโซนข้ามรอบ refresh
🍽️
SaleMode Filter
แต่ละสถานีกรอง SaleMode ได้อิสระ เช่น ครัวดูเฉพาะ Dine-in, บาร์ดูเฉพาะ Delivery
❌
ควบคุมสินค้าหมด
กด "สินค้าหมด" จากหน้าจอ KDS ได้เลย ค้นหาชื่อ toggle สถานะหมด/มี ส่งข้อมูลกลับ Pixel POS ทันที
🔀
แสดงโต๊ะย้าย
การ์ดแสดง badge "ย้ายโต๊ะ" (สีน้ำเงิน) เมื่อ order มีการย้ายโต๊ะ เชฟรู้ทันทีว่าควรส่งไปโต๊ะไหน
👨‍🍳
Staff Login บน Topbar
กรอกรหัสพนักงานจากหน้าหลักโดยตรง บังคับ login ก่อน checkout ทุกช่องทาง บันทึก activity log
📐
ปรับขนาด Card & Font
เลือกขนาดการ์ด S/M/L/XL และ Font Scale 85–130% รองรับจอทุกขนาดตั้งแต่ tablet ถึงจอ TV
📡
DB Offline Banner
แสดงแถบแดงเมื่อขาดการเชื่อมต่อ 3 รอบติดกัน พร้อมปุ่มลองใหม่ หายเองเมื่อกลับมา online
🏪
Multi-KDS หลายจุด
ติดตั้งหลายสถานีบน IIS เดียวกัน ผ่าน subfolder แต่ละจุด settings แยกกัน ไม่ปนกัน
🔐
Screen Lock
ล็อคหน้าจอเมื่อไม่ใช้งาน ป้องกันกดโดยไม่ตั้งใจ รองรับหลายเครื่องพร้อมกัน
📋
Activity Log
บันทึกทุก checkout / undo / confirm พร้อมรหัสพนักงาน วันเวลา และเมนู ใช้ตรวจสอบย้อนหลังได้
